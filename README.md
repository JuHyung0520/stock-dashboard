# 📈 내 주식 보드

개인용 로컬 주식 대시보드. 관심종목 시세(국내+미국), 투자자별 수급(개인/외국인/기관), 최신 뉴스, 지수/환율을 한 화면에서 본다.

## 실행

```bash
node server.js
```

브라우저에서 http://localhost:8787 열기. 설치할 패키지 없음 (Node 18+).

여덟 화면이 있다. 상단 내비게이션은 `public/nav.js` 한 곳에서 렌더한다.

| 경로 | 화면 | 하는 일 |
|---|---|---|
| `/` | 대시보드 | 관심종목 시세·호가·수급·뉴스 |
| `/flow` | 세력 좌표 | 투자자별 수급 — 누가·며칠째·평소 대비 |
| `/terminal` | 터미널 | 삼전·하닉 재무 + 상대수익률 + 반도체 24시간 |
| `/idx` | 지수 | KRX 현물 + 코스피200 야간 선물 환산 |
| `/marketcap` | 시총비교 | 두 종목 시총 추이·격차·역전 이력 |
| `/peak` | 전고대비 | 낙폭 + 회복에 필요한 상승률 |
| `/ram` | 램값 | 메모리 반도체 지수 24시간 + 연동 강도 |

## 램값 (`/ram`)

⚠️ **이 값은 램 칩 가격이 아니다.** 이름 때문에 DDR5 계약가처럼 읽히지만,
`DRAMUSDT`의 기초자산은 **티커 DRAM인 미국 상장 메모리 반도체 ETF**다. 거래소 API로 직접 확인했다:

- `fapi/v1/exchangeInfo` → `underlyingType: "EQUITY"` (금 `XAUUSDT`는 `COMMODITY`로 따로 있다)
- `fapi/v1/constituents` → `dxfeed DRAM:USLF24` · `kaiko KK_RFR_DRAMUSD` · `pyth DRAM`
  — 마이크론(`MU:USLF24`)과 완전히 같은 '미국 상장 종목' 템플릿
- 요일별 변동성: 평일 4.1~6.7% vs 토 1.31% / 일 1.78% — 미국 증시 리듬을 따른다

그럼에도 보는 이유는 **24시간 거래**다. 국장이 열리기 전 아침에 밤사이 메모리 섹터가
어디로 갔는지 알 수 있고, 그게 하이닉스·삼전 시초가의 힌트가 된다.
그래서 '국장 마감 이후 변화'를 주인공으로 놓는다.

메모리주와의 상관·베타도 낸다(일간 수익률 기준, 타임스탬프로 명시 정렬).
DRAM 자체가 메모리주 바스켓이라 높게 나오는 건 당연하고, **읽을 값은 종목 간 차이**다 —
하이닉스 r=0.95/β=1.00 vs 엔비디아 r=0.57/β=0.19로 메모리주와 로직주가 갈린다.

## 하닉 ADR (`/adr`)

SK하이닉스는 미국에서 ADR(`SKHY.O`)로도 거래된다. 김프의 주식 버전.

**이 페이지의 급소는 프리미엄이 아니라 ADR 비율이다.** 1 ADR이 보통주 몇 주분인지 틀리면
프리미엄이 통째로 헛것이 된다. 그런데 어느 API도 비율을 직접 주지 않는다 → 역산한다:

```
네이버 ADR 시가총액 ÷ ADR 주가 ÷ 발행주식수(730,492,365) = 9.9777 → 10
```

하드코딩하지 않고 **매 요청마다 다시 계산해서 근거와 함께 화면에 노출**한다.
발행주식수나 소스가 바뀌면 거기서 바로 드러난다.

교차 검증 — 네이버 ADR 시총(1,641조) vs 한국 실제 시총(1,279조) = **+28.3%**,
가격 직접 비교(ADR×10×환율 vs 한국가) = **+28.6%**. 두 방법이 일치하므로 비율 10이 맞고
프리미엄은 실재한다.

⚠️ 네이버 폴링이 직전 정규장 종가에 머무는 동안 토스 캔들·HL 선물은 다음 세션을 반영하는 일이 있다
(실측: 네이버 163.08 vs 토스·HL 167.5). 헤드라인은 가장 신선한 값으로 낸다.

⚠️ HL `xyz:SKHY`는 `markPx == oraclePx`다 — 독립적 가격발견이 아니라 오라클(ADR 현물 피드) 추종이다.
"선물이 따로 말해주는 가격"처럼 읽히지 않게 화면에 명시한다.

## 알림 (`/alerts`)

브라우저를 닫아도 동작하는 게 존재 이유다. launchd가 60초마다 `alert.js`를 깨운다.

```bash
launchctl load ~/Library/LaunchAgents/com.jk.stock-alert.plist
```

**알림 폭주 방지 3단** — 60초마다 실행되므로 "조건이 참이면 알린다"로 짜면
6시간 반 동안 390번 울린다.

1. **교차 판정** — 상태가 아니라 경계를 넘은 순간에만 발화. 첫 실행(prev 없음)은 절대 발화하지 않는다.
2. **히스테리시스** — 경계 근처 진동 방어. 발화 후 일정 폭 되돌아와야 재무장.
3. **쿨다운** — 1·2단에 버그가 있어도 폭주를 막는 최후 안전망.

설정은 `alerts.json`에 파일로 내려간다. localStorage는 브라우저 안에만 있어서
Node 데몬이 읽을 수 없기 때문이다 — `/alerts` 페이지만 서버 API(`GET/PUT /api/alerts`)를 쓴다.

**한계 (숨기지 않는다)**
- `osascript`의 exit 0은 "알림이 화면에 떴다"를 증명하지 않는다. 방해금지 모드면 조용히 삼켜진다.
  → 소리는 `afplay`로 따로 내서 알림 권한과 무관하게 들리게 했다.
- `StartInterval`은 시스템이 자는 동안의 발화를 놓친다(`man launchd.plist`).
  맥북을 닫아둔 구간은 알림이 없고, 깨어난 뒤 prev가 낡아 갭이 여러 라인을 한 번에 통과한다.
  → 10분 넘는 공백 뒤에는 기준만 다시 잡고 "알림 재개" 한 줄만 띄운다.
- `osascript`는 `on run argv` 인자 전달을 쓴다. 문자열 보간 방식은 메시지에 큰따옴표가
  들어가면 syntax error(-2740)로 죽는다(실측 — `wrap.js`에 이 패턴이 아직 남아 있다).

## 지수 (`/idx`)

낮에는 KRX 현물, 밤에는 Hyperliquid 선물이 주인공이 된다.
국장은 15:30에 닫히지만 코스피200 선물(`xyz:KR200`)은 24시간 돌기 때문에,
마감 후 미국장이 흔들리면 다음 날 시초가의 힌트를 먼저 준다.

```
코스피 야간 추정 = 코스피 × (xyz:KR200 ÷ 코스피200 현물)
```

선물/현물 비율(베이시스)을 코스피에 그대로 옮긴다. 장중에는 이 값이 실제 코스피 옆에
나란히 표시되므로 식이 맞는지 화면에서 바로 검산된다.

⚠️ Hyperliquid xyz에는 상장만 되고 거래가 없는 심볼이 섞여 있다(VIX·DXY·NIFTY·KRW 등 —
미결제약정과 24h 거래대금이 모두 0). 마크 가격이 고정된 껍데기라 `stale`로 표시해
값으로 읽히지 않게 막았다.

## 시총비교 (`/marketcap`)

`시총 = 일별 수정종가 × 현재 발행주식수`. 발행주식수는 토스가 유일한 소스다.

⚠️ **이 근사는 액면분할에는 정확하지만 감자에는 완전히 틀린다.**
액면분할은 주식수가 늘고 주가가 그만큼 내려가 시총이 안 변한다. 반면 감자·유상증자·자사주
소각은 시총 자체가 변한다. 실측: SK하이닉스는 2002년 21:1 감자를 겪어 네이버 수정주가가
1999년 종가를 718,108원으로 잡는다. 여기에 현재 주식수를 곱하면 시총 524조 —
당시 코스피 전체 시총보다 크다. 그래서 **기간 상한을 10년으로 제한**했다.

## 전고대비 (`/peak`)

핵심은 낙폭이 아니라 **비대칭**이다. −50%는 +100%가 있어야 본전이라서,
낙폭과 '회복에 필요한 상승률'을 항상 나란히 놓는다.
지수도 종목과 같은 방식으로 다룬다 — 코스닥은 2000-03-10 고점(2,925.50) 대비 아직 −72.7%다.

## 장기 데이터 소스 — 네이버 siseJson

토스 캔들은 200개가 상한이라 3년·10년 비교가 불가능하다. 장기 구간은 여기서만 나온다.

```
https://api.finance.naver.com/siseJson.naver?symbol=005930&requestType=1
  &startTime=19900101&endTime=20260821&timeframe=day
```

- **`Referer: https://finance.naver.com/` 헤더가 없으면 거부당한다.**
- 코스피 9,453행(1990-01-04~), 삼성전자도 동일. 지수(KOSPI/KOSDAQ/KPI200)도 같은 경로.
- 응답이 JS 배열 리터럴이라(헤더 행만 홑따옴표) `JSON.parse`가 안 된다 → 행 단위 정규식으로 파싱.
- `timeframe=week|month`는 빈 응답 → 서버에서 다운샘플한다.
- ⚠️ 시/고/저가가 전부 0인 결측 행이 드물게 있다(실측: 코스피 2007-03-02). 그대로 두면
  기간 최저가가 0이 되어 '저점 대비'가 통째로 깨진다 → 0이면 종가로 메운다.

## 차트

라이브러리를 쓰지 않는다. `public/chart.js`가 SVG를 직접 그린다.

- `Chart.line` 꺾은선(여러 계열·기준선·끝점 태그) / `Chart.candles` 캔들 / `Chart.spark` 스파크라인
- `Chart.timeAxis(candles)` — 라벨 형식을 간격 이름이 아니라 **실제로 걸친 기간**으로 정한다.
  1시간봉 200개는 8일치라 시:분만 찍으면 "04:00 → 22:00 → 17:00"처럼 거꾸로 읽힌다.
- viewBox 1000×H 고정 + `preserveAspectRatio="none"` — 반응형 계산이 필요 없다
- 십자선: 마우스 위치의 실제 값을 숫자로 읽어준다. 장기 차트에서 눈대중을 없애려는 것.

## ETF 괴리율 (`/etf`)

레버리지·인버스 ETF의 현재가 vs iNAV 괴리율. 기본 목록은 단일종목 레버리지 6종 + KODEX 레버리지/인버스
(검색으로 추가/삭제, localStorage 'etf-v1').

- **실시간 괴리** = 최신 시세(5초) vs iNAV(20초 캐시) 직접 계산 — 네이버 제공치는 참고로 병기
- |괴리| 큰 순 정렬 + 1% 이상은 테두리 강조 — 벌어진 놈이 위로
- 상단 **세션 타임라인**: KR 정규/NXT/US 정규(서머타임 동적 계산)를 24h 띠로, 현재 시각 마커·진행 중 하이라이트

## 해외 선물 환산가 (대시보드 사이드바)

**Hyperliquid에 상장된 한국주식 무기한선물**(xyz:SMSN 삼성전자, xyz:SKHX SK하이닉스)의 달러 시세를
업비트 USDT/KRW로 환산해 국내 시세와의 괴리를 보여준다. raoni.xyz 홈의 "김프" 기능.
선물은 24시간 거래라 **장 마감 후·주말에 국내 시세의 유일한 실시간 힌트**가 된다.

- 비교 기준 자동: 장중=현재가 / 마감 후=NXT(열려 있으면) / 아니면 종가
- 시간당 펀딩비, 선물 전일比 함께 표시 · 10초 갱신 (서버 캐시 5초)
- 데이터: `api.hyperliquid.xyz/info` (`{"type":"metaAndAssetCtxs","dex":"xyz"}`) + `api.upbit.com/v1/ticker` — 둘 다 키 불필요 공개 API
- HL에 상장된 한국주식은 현재 삼전·하이닉스 2종뿐 (상장 늘면 server.js MAP에 추가)

## 해외 선물 환산가 (김프) — 대시보드 사이드바

비교 기준을 고를 수 있다(자동/현재가/NXT/전일종가). 같은 선물 가격이라도 무엇과 비교하느냐에 따라
프리미엄이 2~3%p 달라지고, 주말엔 금요일 종가와 비교하게 되므로 특히 그렇다.

⚠️ **고친 버그**: 펀딩비를 시간당 값으로 소수 2자리로 찍고 있어서 화면에 항상 `−0.00%`로 나왔다.
연율로 환산하니 **−51% / −76%**(숏이 롱에 지급) — 보이지 않던 쏠림이 드러났다.
HL 펀딩이 시간당인 것은 `fundingHistory` 타임스탬프 간격이 정확히 60분인 것으로 확인했다.

## 내 자산 (`/assets`) — 평단 손익계산기 (멀티 계좌)

일반·ISA·연금을 나눠 관리한다. 계좌별 소계와 전체 합산을 같은 코드(`totals()`)로 낸다.

**저장 스키마가 v2로 올라갔다.** `assets-v1`은 읽기 전용으로 동결하고 백업을 남긴 뒤
`assets-v2`에만 쓴다. 문제가 생기면 `assets.js`만 되돌리면 원상복구된다.

⚠️ **행 식별은 고유 `hid`다.** 처음엔 `aid|id` 복합키를 썼는데, 계좌를 지워 보유를 다른 계좌로
옮길 때 그쪽에 같은 종목이 있으면 키가 겹쳐 한 행을 고치면 다른 행이 바뀐다.
계좌 삭제 시 중복 종목은 차수·매도 기록을 병합하고 `firstBuyDate`는 이른 쪽을 남긴다.

**계좌별로 나누지 않는 것** — 거래세율은 전역이다. ISA·연금의 혜택은 양도세·배당세 축이지
증권거래세 면제가 아니다. 통화도 계좌별로 섞지 않는다(원화와 달러는 끝까지 분리, 환산하지 않는다).

**같이 고친 기존 버그 3개**
1. **5초 폴링이 커서를 파괴** — `refreshQuotes → render`가 조건 없이 목록을 재구성해
   평단을 5초 넘게 타이핑하면 커서가 날아갔다. `activeElement` 가드 추가.
2. **실현손익 인덱스 어긋남** — 필터된 배열을 원본 인덱스로 조회해서, 미완성 매도 기록이 끼면
   그 뒤 행들의 손익이 한 칸씩 밀렸다.
3. **export에 그리드 누락** — "백업했다"고 믿고 그리드 체결 기록을 잃을 수 있었다.

raoni.xyz/calc를 참고해 만든 보유자산 평가 화면. **데이터는 이 브라우저(localStorage)에만 저장, 서버 전송 없음.**

- **분할매수 차수별 입력** (평단×수량) → 가중 평단 자동 계산
- 실시간 평가 (5초) — 국내는 **NXT 장전·장후 가격**도 현재가 밑에 표시, 미국 종목도 지원(달러 별도 합산)
- **매도 거래세 차감** — 0.2 / 0.18 / 0.15% / 미적용 선택, **ETF는 검색 시 자동 판정해 면제**

## 세력 좌표 (`/flow`)

"누가 샀나"가 아니라 **"각 주체가 지금 어떤 포지션에 서 있나"**를 본다.

- **오늘의 세력 판정** — 시장을 실제로 움직인 주체 하나를 지목 + 100일 경험적 순위
- **기준선 카드** — 주요 4주체의 오늘 값을 **전일 / 5일평 / 20일평**과 나란히. 숫자 하나로는 뜻이 안 생긴다
- **포지션 타임라인** — 11주체 × 20거래일 격자가 화면 본체. 색=방향, 농도는 **3단계 양자화**.
  연속 농도로 칠했더니 수급은 거의 매일 값이 있어 격자가 색의 벽이 됐다 — 이 격자의 목적은 크기가 아니라
  **연속과 전환점**이라, 3단계로 끊으니 연속 구간이 덩어리로 읽힌다. `연속만 강조` 토글을 켜면
  3일 미만 고립된 날이 눌리고 진짜 흐름만 남는다. `기관 세부` 토글로 행을 4개로 줄일 수 있다.
  격자 위에 마우스를 올리면(또는 ←→ 키) **그날 전체가 한 줄로 정렬**된다 (일 단위 타임 스크러버)
- **기관 내부 대립** — 7세부를 사는 쪽 / 파는 쪽으로 마주 세움 + 내부 분열도
- **방향을 튼 주체** — 4일 이상 한 방향이다 오늘 반전한 주체 ("배신자")
- **관심종목 세력 스캐너** — 수급 강도(순매수÷20일평균거래량)로 정규화해 종목 크기와 무관하게 비교
- **검사 로그** — 무엇을 몇 건 검사했고 무엇이 결측인지. 침묵이 고장이 아님을 증명

### 통계 방법론 (실측으로 정해진 것들)

- **평균이 아니라 중앙값·MAD (로버스트 z)** — 코스피 외국인이 20일 평균 −34억인데 오늘 +25,010억인 날조차
  일반 z는 0.78이 나온다. 과거 극단값이 표준편차를 부풀려 신호를 죽인다.
- **"z=2.8"이 아니라 "100일 중 2위"** — 금융 시계열은 정규분포가 아니라 시그마의 확률 해석이 실제와 안 맞는다.
- **잔고성 계열(융자·대차·보유율)은 1차 차분 후 평가** — 수준값에 z를 씌우면 추세 때문에 상시 이상으로 뜬다
  (실측: 융자잔고 수준값 z=1.73 vs 차분 z=−0.11).
- **장중 잠정치는 null로 전파** — 0으로 채우지 않는다. 종목별 기관 세부·개인은 장 마감 후 확정치에서 채워진다.

### 검토했으나 폐기한 것

- **세력 평단선** (주체별 추정 평단): 순매수 가중은 발산하고(반례: 평단이 −80,000원), 총매수 가중은
  전 주체가 같은 값으로 수렴한다(실측: 외국인 242,482 / 기관 241,873 / 개인 240,757 — 차이 0.7%).
  일별 종가만으로는 주체별 체결가를 구분할 수 없다. 대신 **매수평단 vs 매도평단**(타이밍 우열)은 유효.
- **전례 스트립** ("지난번 이랬을 때 3번 중 2번은…"): 매칭 표본이 1~5건이고 그마저 같은 사건 구간에서
  나와 서로 독립이 아니다. 통계가 아니라 일화.
- **본페로니 보정**: 지표 간 상관이 강해(개인 ≈ −(외국인+기관)) 과보정. 경험적 순위로 대체.

  - **미국 종목도 지원**하지만 소스가 달라서 표시 항목이 다르다:

    라벨을 `200일 범위`로 다르게 표기한다 (국내는 `52주 범위`).

- **종목 상세** — 종목 행 클릭 → 6개 탭
  - `호가` **매수벽/매도벽 그래프**. 매도 10단계(위·파랑) + 매수 10단계(아래·빨강), 막대 = 잔량.

## 토스증권 Open API 설정

수급 데이터는 토스증권 공식 Open API를 쓴다 (`toss.js`). 설정은 `.env` 하나:

```
TOSS_CLIENT_ID=...
TOSS_CLIENT_SECRET=...
```

발급: 토스증권 PC웹(WTS) → 설정 → Open API → **Open API Key 설정**.
같은 화면의 **허용 IP 관리**에 이 컴퓨터의 공인 IP를 등록해야 한다 (미등록 시 전부 403).

- **키가 없거나 토스 호출이 실패하면 자동으로 네이버로 폴백**한다 (검증 완료). 대시보드는 어느 쪽이든 동작하고, 패널에 현재 출처가 표시된다.
- 토큰은 24h, refresh 없음. **클라이언트당 유효 토큰 1개** — 재발급하면 이전 토큰이 즉시 죽으므로 `toss.js`가 프로세스 내에서 하나만 들고 돌려쓴다 (만료 5분 전 갱신, 동시요청 시 발급 1회로 합침).
- Rate limit (초당): `MARKET_DATA` 15 · `STOCK_TRADING_TREND` 10 · `MARKET_INDICATOR` 10 · `MARKET_INFO` 3. 실제 한도는 응답 헤더 `X-RateLimit-Limit`.

토스가 네이버보다 나은 점: 기관 **7개 세부분류**(금융투자·보험·투신·사모·은행·기타금융·연기금), 시장 수급이 **매매대금**(네이버 종목수급은 주식수만), 외국인 보유율, 기타법인.

아직 안 쓰고 있는 토스 엔드포인트: `/price-limits` 상하한가 · `/trades` 체결내역 · `/market-calendar` 장운영시간 ·
계좌·주문 계열 전부(`/accounts`, `/holdings`, `/orders`, `/conditional-orders`).
`/candles`는 세력 좌표에서 이격도·거래량배수 계산에 쓰고 있다.

토스에 **없는 것**: 뉴스(네이버 유지), **웹소켓**(REST 폴링만, "추후 지원 예정").

## 참고

- 등락 색상은 국내 관례(상승 빨강, 하락 파랑).
- 종목별 수급은 네이버가 **주식수 단위**로만 제공 (금액 아님).
- 시장 수급 잠정치는 장중 계속 갱신되고 다음 거래일에 확정됨.
